# Drawing Things 상세 사용 가이드 (AI 학습용 데이터)

이 문서는 Apple Silicon 기기에서 실행되는 로컬 AI 이미지 생성 앱인 **Drawing Things**의 상세 사용법을 AI 모델이 학습하기 좋은 구조로 정리한 가이드입니다.

---

## 🚀 1. 시스템 개요 및 초기 설정
* **플랫폼 아키텍처**: Apple Metal 및 CoreML 기반의 로컬 연산 엔진.
* **데이터 보안**: 인터넷 연결 없이 기기 내부에서 모든 이미지 생성 프로세스 진행.
* **권장 사양**: 
    * 최소: 8GB 통합 메모리 (SD 1.5 모델 위주)
    * 권장: 16GB(M4 포함) 이상 통합 메모리 (SDXL 및 Flux 모델 지원) - **정확도:높음**

---

## 📂 2. 모델(Model) 관리 및 최적화
AI 모델을 앱에 등록하고 최적화하는 단계입니다.

1.  **모델 가져오기**:
    * `Select Model` -> `Manage` 메뉴 진입.
    * 외부 사이트(Civitai 등)의 `.safetensors` 또는 `.ckpt` 파일 URL 입력 또는 로컬 파일 업로드.
2.  **CoreML 변환**:
    * 앱 내에서 모델 선택 시 자동 또는 수동으로 CoreML 가중치 변환 수행. (연산 속도 최대 2배 향상)
3.  **VAE 설정**:
    * `VAE` 섹션에서 색감 개선을 위한 별도의 VAE 파일(예: vae-ft-mse-840000) 지정 가능.

---

## ⚙️ 3. 이미지 생성 파라미터(Parameters) 가이드
생성 결과물의 품질을 결정하는 핵심 수치들입니다.

* **Prompt (긍정 프롬프트)**: 원하는 이미지의 요소를 영어로 입력 (예: `a high-quality portrait of a cybernetic cat`).
* **Negative Prompt (부정 프롬프트)**: 제외할 요소 입력 (예: `blurry, distorted, low quality`).
* **Sampling Steps**: 노이즈 제거 횟수. 일반적으로 **20~35단계**가 최적. (정확도:높음)
* **Guidance Scale (CFG)**: 프롬프트 준수 강도. **7.0~9.0** 사이 권장.
* **Sampler**: `DPM++ 2M Karras` (속도/품질 균형), `Euler a` (부드러운 화풍).

---

## 🎨 4. 고급 기능 (Advanced Features)
단순 프롬프트 입력을 넘어선 정밀 제어 기능입니다.

### 📌 LoRA (Low-Rank Adaptation)
* **용도**: 특정 화풍, 캐릭터, 사물을 미세 조정된 가중치로 적용.
* **적용**: `LoRA` 탭에서 파일을 선택하고 가중치(Strength)를 **0.4~0.8** 사이로 조절.

### 📌 ControlNet
* **용도**: 이미지의 구도, 포즈, 외곽선을 강제로 제어.
* **주요 모드**: 
    * `Canny`: 외곽선 추출.
    * `OpenPose`: 인체의 자세 제어.
    * `Depth`: 원근감 및 깊이 제어.

### 📌 Inpainting & Outpainting
* **Inpainting**: 이미지의 일부를 마스킹한 후 프롬프트를 통해 해당 부분만 수정.
* **Outpainting**: 이미지의 캔버스 크기를 늘리고 확장된 영역을 주변 맥락에 맞게 생성.

---

## 🛠 5. 하드웨어별 최적화 팁
(사용자 기기 정보: Mac Mini M4 16GB 기준 - **정확도:높음**)

* **메모리 관리**: 대형 모델(SDXL) 사용 시 다른 무거운 앱 종료 권장.
* **해상도 설정**: 16GB RAM 환경에서는 기본 **1024x1024(SDXL)** 해상도 생성이 원활함.
* **Upscaling**: `Real-ESRGAN` 또는 `4x-UltraSharp` 알고리즘을 사용하여 저해상도 결과물을 고품질로 변환.

---

## 📊 6. 요약 및 주의사항
* **학습 핵심**: Drawing Things는 **로컬 환경**에서 **Metal 가속**을 활용하는 점이 핵심이며, 모델 변환 과정이 성능을 좌우함.
* **주의**: 앱 업데이트 속도가 빠르므로 메뉴의 위치는 버전별로 상이할 수 있음. (**정확도:중간**)
